# Безопасность баз данных: практические задания

**Выполнил:** Meorwik

Решения разбиты по неделям. Каждая неделя — отдельная папка со своим `docker-compose.yml` (PostgreSQL 16), SQL-скриптами, выводом СУБД и отчётом.

| Неделя | Практическое занятие | Тема | Отчёт |
|--------|----------------------|------|-------|
| 3 | ПЗ №3 | Создание пользователей, аутентификация, права доступа, блокировка учётных записей | [week-03/report.md](week-03/report.md) |
| 4 | ПЗ №4 | Авторизация: матрица доступа, `GRANT`/`REVOKE`, роли, минимальные привилегии | [week-04/report.md](week-04/report.md) |
| 5 | ПЗ №5 | Ролевая модель RBAC: роли, иерархия ролей, разделение обязанностей | [week-05/report.md](week-05/report.md) |
| 6 | ПЗ №6 | Защита на уровне столбцов, представлений (`VIEW`) и строк (RLS) | [week-06/report.md](week-06/report.md) |

## Быстрый старт

```bash
cd week-03
docker compose up -d
docker compose exec db psql -U postgres -d university -f /checks.sql
docker compose down
```

У каждой недели свой порт на хосте (`55443`–`55446`), поэтому контейнеры можно поднимать одновременно.
