# Занятие 13. Облачная БД (DBaaS)

**Цель:** перенести БД в облачный PostgreSQL (Neon / Supabase), проверить данные, сравнить скорость.
**Go вместо `migrate_to_cloud.py`:** `cmd/migrate/main.go` на `pgx` (`CopyFrom` / `CopyTo`).

## Структура
```
13-cloud-dbaas/
  go.mod
  cmd/migrate/main.go   # create tables + COPY + сверка count(*)
  cmd/bench/main.go     # медиана времени запроса: local vs cloud
  ARCHITECTURE.md       # схема «приложение → API → облачная БД», риски
  REPORT.md             # числа времени, объяснение различий
```

## Секреты
Строка подключения — **только** env: `CLOUD_DSN` (и `LOCAL_DSN`). Не в коде, не в git (`.gitignore`, `.env` не коммитить), не в чатах. Утекла → сменить пароль в панели провайдера.

## Задания
1. Проверить тариф/требования регистрации (карта, телефон). Нельзя — сообщить преподавателю.
2. Создать проект, получить DSN → `export CLOUD_DSN=...`.
3. `go run ./cmd/migrate`: создаёт таблицы (4), копирует через COPY, сравнивает число строк local vs cloud.
4. Подключиться из pgAdmin, выполнить запрос из занятия 7, сравнить результат.
5. `go run ./cmd/bench`: медиана N прогонов запроса локально и в облаке; записать. Причины различий: расстояние, нагрузка, регион.
6. `ARCHITECTURE.md`: схема (рисунок/5–6 строк); что в облаке, что локально; риски — пароль, отказ провайдера, стоимость.
