# Архитектура: приложение → API → облачная БД

```
  браузер / Postman / Go-клиент
              │  HTTPS, заголовок X-API-Key
              ▼
   Go API (Gin) на ноутбуке  ──── DATABASE_URL (env) ────►  облачный PostgreSQL (Neon / Supabase)
              │                                              │  TLS, sslmode=require
              ▼                                              ▼
   локальный Postgres (Docker)                       таблицы titles, checkout_facts,
   исходный срез, big_checkouts,                     subjects, title_subjects
   эксперименты (индексы, партиции)
```

## Что где хранится
| Место | Что лежит |
|---|---|
| Облако | рабочие данные: 4 таблицы схемы (5000 + 5000 + 6536 + 18961 строк) |
| Ноутбук | `raw_checkouts`, справочник `ils_dictionary`, `big_checkouts` на 1 млн строк, партиции, MongoDB, исходные CSV, код API |
| Переменные окружения | `DATABASE_URL`, `CLOUD_DSN`, `LOCAL_DSN`, `API_KEY` — не в коде и не в git |

## Риски
| Риск | Что может случиться | Что делать |
|---|---|---|
| Пароль / строка подключения | в строке есть пароль; утечка в чат, репозиторий или лог = чужой доступ к данным | только в env, `.env` в `.gitignore`; при утечке сразу сменить пароль в панели провайдера |
| Отказ провайдера | облако недоступно → API не отвечает | локальная копия + `pg_dump` (занятие 15), понятная ошибка 503 вместо падения |
| Стоимость | бесплатный тариф ограничен по объёму, времени работы и числу соединений; при превышении сервис усыпляет БД или просит оплату | следить за лимитами, держать большие учебные таблицы только локально |
| Задержка | каждый запрос идёт по сети: дольше, чем локально | пул соединений, меньше запросов за раз, регион ближе к пользователю |
| Открытый доступ | БД доступна из интернета | TLS (`sslmode=require`), отдельная роль с минимальными правами (занятие 15), не использовать суперпользователя в приложении |
