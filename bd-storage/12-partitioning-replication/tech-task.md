## Часть А. Партиционирование (на `big_checkouts` из занятия 9)
1. `psql -d seattle_library -f sql/01_partitioning.sql`; число строк в `checkouts_part` == `big_checkouts`.
2. Сравнить время/план `WHERE checkoutyear = 2019` на `big_checkouts` и `checkouts_part`; указать, какие партиции прочитаны (pruning).
3. Запрос по `materialtype` без года — ускорение пропало? Объяснить (нет ключа партиции → читаются все).
4. `DETACH PARTITION checkouts_2005_2009` → посчитать строки → `ATTACH PARTITION`.
5. INSERT с годом 2200 → записать ошибку; решение — `DEFAULT`-партиция.
6. Хеш-партиционирование по `id` на 3 части: `SELECT tableoid::regclass, count(*)` — равномерность; связь с шардингом.

## Часть Б. Репликация и отказ (по инструкции преподавателя)
Primary + replica (логическая репликация). Записать наблюдения:
- что дошло на replica;
- что случилось при остановке primary;
- какая запись возможна на replica;
- что не реплицируется (DDL).
